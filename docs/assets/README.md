# Docs assets

Place screenshots and short demo recordings here. Suggested filenames (referenced from the root README):

| File | Content |
|---|---|
| `cli-run.png` | Terminal: `uv run mutiny run --no-hosted` on the sample project |
| `hosted-campaign.png` | Hosted UI campaign / lineage view |
| `policy-yaml.png` | Excerpt of `policy.yaml` with a clear tool-use rule |
| `mutiny-demo.gif` or `.webm` | Optional short loop of init → run → test |

Keep images reasonably sized (&lt; ~1–2 MB each). Prefer PNG/WebP for stills.
